# Late-Nyt-Listen-s

A minimal static web project containing a simple frontend app built with HTML, CSS, and JavaScript.

## Contents
- `index.html` — main page
- `script.js` — JavaScript logic
- `style.css` — styles

## Overview
This repository contains a small client-side web app. Open `index.html` in a browser to run the app locally.

## Setup
No build tools or dependencies are required.

- Option 1 (quick): Open `index.html` directly in your browser.
- Option 2 (recommended for development): Serve the folder with a static server (e.g., VS Code Live Server or Python simple HTTP server):

  ```powershell
  # from the project root
  python -m http.server 8000
  # then visit http://localhost:8000
  ```

## Development
- Edit `index.html`, `style.css`, and `script.js` and refresh the browser to see changes.
